UrBackup GRUB APT repository

Debian grub2 packages with a patch that lets grub-probe/grub-install resolve UrBackup device-mapper snapshot devices to the real root device. Built from github.com/uroni/urbackup-grub.

Supported: Debian 12 (bookworm) and Debian 13 (trixie), amd64.

Setup

sudo curl -fsSL -o /usr/share/keyrings/urbackup-grub.gpg https://uroni.github.io/urbackup-grub/urbackup-grub.gpg
. /etc/os-release
sudo tee /etc/apt/sources.list.d/urbackup-grub.sources <<EOF
Types: deb
URIs: https://uroni.github.io/urbackup-grub/$VERSION_CODENAME
Suites: $VERSION_CODENAME
Components: main
Signed-By: /usr/share/keyrings/urbackup-grub.gpg
EOF
sudo apt update && sudo apt upgrade
